The Problem

Riot Esports' mid-season lull has no story-driven way for fans to connect personally with pro players between splits. Existing in-client seasonal gaming events — Spirit Blossom, Star Guardian — proved the format works for skins, but nothing applied it to esports fandom itself.

What I Built

  • A personality- and playstyle-based matching algorithm pairing fans with pro players and teams.
  • An in-client visual-novel-style narrative layer with branching dialogue.
  • Quests that unlock through real in-game actions — tracked via Riot's Match History API — with rewards issued through the existing cosmetics pipeline.
  • The full system architecture: client UI (React/TypeScript/Pixi.js over Riot's CEF), backend (Node.js/PostgreSQL/Redis), and integration with Riot's SSO, telemetry, and reward services.

Outcome & Impact

Recognized by Riot Games leadership as the strongest submission for technical feasibility and user impact, with features recommended for implementation.
