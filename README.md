# Portfolio Website

Personal portfolio showcasing game development and interactive media projects.

## Technical Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Features:**
  - Responsive design (mobile-first)
  - Custom Vimeo video controls
  - Dynamic page navigation
  - Project filtering system

## Implementation Highlights
- Vanilla JavaScript (no frameworks)
- CSS Grid/Flexbox layouts
- Custom video player controls via Vimeo API
- Page state management for multi-view interface

## Design Decisions
- Dark theme optimized for visual media
- Minimal dependencies for fast load times
- Accessible navigation and controls
- Clean typography hierarchy

## Deployment
Hosted via GitHub Pages with custom domain support.
